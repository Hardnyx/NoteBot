NOTEBOT PORTABLE
================

1. Extract the whole ZIP before opening the program.
2. Run NoteBot\NoteBot.exe.
3. Keep NoteBot.exe together with the app and runtime folders.

This portable edition does not need Java installed and keeps its notes in
NoteBot\data. To keep or move your notes, copy the whole NoteBot folder.

If you would rather do a normal single file installation, use
NoteBot-Setup-<version>.exe: it does not ask for administrator rights and keeps
its notes in %LOCALAPPDATA%\NoteBot.

The application and its runtime are 64 bit. The executable is not signed, so
Windows may show a SmartScreen warning.
